# Urgent Plumbing - Modern Plumbing Services Website

A modern, minimalist, and responsive website for a plumbing services company.

## Features

- **Modern Design**: Clean, minimalist aesthetic with smooth animations
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth scrolling, animated sections, and mobile menu
- **Contact Form**: Functional contact form with validation
- **SEO Friendly**: Semantic HTML with proper meta tags
- **Fast Loading**: Lightweight code with optimized performance

## Sections

1. **Hero Section**: Eye-catching header with call-to-action buttons
2. **Services**: Grid of 6 service offerings with icons
3. **Features**: Highlighted stats and key differentiators
4. **About**: Company information and value propositions
5. **Contact**: Contact form and contact information
6. **Footer**: Quick links and additional information

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)
- SVG Icons

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required!

## Customization

### Update Contact Information
Edit the following in `index.html`:
- Phone numbers
- Email addresses
- Service area information

### Change Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #0066CC;
    --primary-dark: #0052A3;
    --secondary-color: #00AAFF;
}
```

### Connect Contact Form to Your Email
**IMPORTANT:** The contact form is ready to use! You just need to add your email address.

1. Open `index.html` and find line 274
2. Replace `YOUR_EMAIL_HERE` with your email address
3. That's it! The form will send messages to your inbox

For detailed instructions, see [FORM_SETUP.md](FORM_SETUP.md)
